How imports work

  1. Upload one or more files — a whole export split into batches is fine. They are held in a draft import; live data does not change. A later file replaces an earlier row with the same Alert ID.
  2. Review & finalize shows exactly what will change, then applies it. Or discard it.

An open vulnerability is marked remediated only when the import contains a newer scan of the same asset (by Asset ID and Last Scan) without that alert. Assets not in the import are never touched, re-uploading an older file changes nothing, and a rejected (unreadable) row never counts as evidence of a fix.

If a remediated alert appears in a newer scan it is reopened. Open alerts whose asset has no newer scan for the configured number of days are flagged Not seen for review — not counted as fixed.
