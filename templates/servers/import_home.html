How server imports work

  1. Upload the whole MFS12 export. Batches are fine. Add the Qualys report too if you want Solution and Results in Herald. Files wait in a draft; live data does not change.
  2. Enter the Power BI total of MFS12 rows, so Herald can confirm every batch is in.
  3. Review & finalize shows exactly what will change, then applies it. Or discard it.

A vulnerability is one server + QID. Server names are matched to CMDB ignoring capitals: the exact name, then the FQDN, then the short name if only one CMDB server has it. Other servers are listed as unassigned.

MFS12 is treated as the complete current list. When you finalize, an open vulnerability missing from it is marked remediated, including those of servers missing from the upload. So upload every batch, unfiltered. A failed file or unreadable row stops remediation where it could be wrong.
